## Selected work

**[BSP](https://github.com/andremassuca/BSP)**  
Reproducible pipeline for postural stability analysis. Centre-of-pressure sway,
jerk and frequency-domain metrics across 3,000+ trials. v1.0 is the version
cited in the JFMK publication.

**[firebot-maze-solver](https://github.com/andremassuca/firebot-maze-solver)**  
Autonomous fire-fighting robot. Arduino Mega, three ultrasonic sensors,
gyroscope heading and a C# desktop application over BLE. Demonstrated at Noite
dos Investigadores 2026.

**[biomat-mcdm](https://github.com/andremassuca/biomat-mcdm)**  
Multi-criteria biomaterial selection with target criteria and robustness
analysis. TOPSIS, WASPAS and VIKOR under Monte Carlo uncertainty.

**[andremassuca.com](https://andremassuca.com)**  
Portfolio with full case studies, including work not public here.
