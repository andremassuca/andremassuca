## Selected work

**[BSP](https://github.com/andremassuca/BSP)**  
Reproducible pipeline for postural stability analysis: centre-of-pressure sway, jerk and frequency-domain metrics across 3,000+ trials. Used in a peer-reviewed study (JFMK, 2026); a follow-up study is in preparation.

**[pulse-studio](https://github.com/andremassuca/pulse-studio)**  
Desktop app for a pulse sensor on an Arduino Uno: live PPG waveform, heart rate and HRV, with CSV recording and replay.

**[firebot-maze-solver](https://github.com/andremassuca/firebot-maze-solver)**  
Autonomous fire-fighting robot. Arduino Mega, three ultrasonic sensors, gyroscope heading and a C# desktop application over BLE. Demonstrated at Noite dos Investigadores 2026.

**[biomaterial-ideal](https://github.com/andremassuca/biomaterial-ideal)**  
Multi-criteria biomaterial selection with target criteria and robustness analysis: TOPSIS, WASPAS and VIKOR under Monte Carlo uncertainty.

**Ultrasound muscle segmentation** (private)  
Deep learning pipeline for rectus femoris cross-sectional area, built during a research internship at FMH. A U-Net-type network exported to ONNX and delivered as a desktop application.
